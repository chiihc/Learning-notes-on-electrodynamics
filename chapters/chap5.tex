\subsection{辅助场$\boldsymbol{H}$}

\subsubsection*{1. 磁场强度 \(\boldsymbol{H}\) 的定义}

磁场强度 \(\boldsymbol{H}\) 是描述磁场的一种物理量, \,其与磁感应强度 \(\boldsymbol{B}\) 有以下关系：
\[
\boldsymbol{B} = \mu_0 (\boldsymbol{H} + \boldsymbol{M})
\]

磁场强度 \(\boldsymbol{H}\) 描述了磁场的源——电流和外部磁场对物质的影响。

在均匀介质中
\[
\nabla \times \boldsymbol{H} = \boldsymbol{J}
\]

在没有磁化的情况下, \,安培环路定律为：
\[
\oint \boldsymbol{H} \cdot d\boldsymbol{l} = I_{\text{free}}
\]
其中, \,\(I_{\text{free}}\) 是通过闭合回路的自由电流。


\subsubsection*{5. 在均匀介质中的表达式}

在均匀介质中, \,磁场强度 \(\boldsymbol{H}\) 的方程可以通过麦克斯韦方程组直接推导得到。通过积分, \,我们可以得到外部电流源产生的磁场强度分布。

对于均匀介质中的直流电流, \,磁场强度 \(\boldsymbol{H}\) 和磁感应强度 \(\boldsymbol{B}\) 满足以下关系：
\[
\boldsymbol{B} = \mu_0 \boldsymbol{H}
\]
其中, \,\(\mu_0\) 为真空的磁导率。

\subsubsection*{6. 磁场强度 \(\boldsymbol{H}\) 和磁感应强度 \(\boldsymbol{B}\) 的关系}

磁感应强度 \(\boldsymbol{B}\) 和磁场强度 \(\boldsymbol{H}\) 之间的关系在物质中通过磁化强度 \(\boldsymbol{M}\) 来描述：
\[
\boldsymbol{B} = \mu_0 (\boldsymbol{H} + \boldsymbol{M})
\]
这一关系表明, \,磁场强度 \(\boldsymbol{H}\) 描述的是由于自由电流产生的磁场, \,而磁感应强度 \(\boldsymbol{B}\) 则同时考虑了自由电流和由物质的磁化效应所产生的磁场。

在没有物质磁化的情况下, \,\(\boldsymbol{M} = 0\), \,此时 \(\boldsymbol{B} = \mu_0 \boldsymbol{H}\)。

\subsubsection*{7. 磁场强度与磁化强度的相互关系}

磁化强度 \(\boldsymbol{M}\) 描述了物质内的自发磁化或由外部磁场引起的磁化。在静态情况下, \,\(\boldsymbol{M}\) 和 \(\boldsymbol{H}\) 之间的关系由材料的磁导率决定。

对于均匀线性材料：
\[
\boldsymbol{M} = \chi_m \boldsymbol{H}
\]
其中, \,\(\chi_m\) 是材料的磁化率。

因此, \,在材料中, \,磁感应强度 \(\boldsymbol{B}\) 与磁场强度 \(\boldsymbol{H}\) 之间的关系可以写作：
\[
\boldsymbol{B} = \mu_0 (1 + \chi_m) \boldsymbol{H}
\]
或者, \,使用磁导率 \(\mu = \mu_0 (1 + \chi_m)\)：
\[
\boldsymbol{B} = \mu \boldsymbol{H}
\]

\subsubsection*{8. 磁场强度的边界条件}

在物质的界面处, \,磁场强度 \(\boldsymbol{H}\) 满足以下边界条件：
- 在界面上的法向分量连续：
  \[
  \boldsymbol{H}_1 \cdot \boldsymbol{n} = \boldsymbol{H}_2 \cdot \boldsymbol{n}
  \]
- 在界面上的切向分量不连续(如果有表面电流)：
  \[
  \boldsymbol{H}_1 \times \boldsymbol{n} - \boldsymbol{H}_2 \times \boldsymbol{n} = \boldsymbol{K}_b
  \]
  其中, \,\(\boldsymbol{K}_b\) 是表面束缚电流密度。


\subsection{磁荷与磁标势方法}


在无自由电流($\boldsymbol J_f=0$)情况下, \,
\begin{equation}
\nabla\times \boldsymbol H = 0
\end{equation}
因此 $\boldsymbol H$ 可表示为标势的梯度：
\begin{equation}
\boldsymbol H = -\nabla \phi_m
\end{equation}


\subsubsection*{2. 等效磁荷的引入}

由
\[
\nabla\cdot \boldsymbol B = 0
\]
代入 $\boldsymbol B=\mu_0(\boldsymbol H+\boldsymbol M)$ 得

\begin{align}
0 &= \mu_0 \nabla\cdot(\boldsymbol H + \boldsymbol M) \\
\nabla\cdot \boldsymbol H &= -\nabla\cdot \boldsymbol M
\end{align}

定义等效体磁荷密度
\begin{equation}
\rho_m \equiv -\nabla\cdot \boldsymbol M
\end{equation}

在界面处, \,由散度定理得到等效面磁荷密度：
\begin{equation}
\sigma_m = \boldsymbol M\cdot \boldsymbol n
\end{equation}

其中 $\boldsymbol n$ 为外法向量。


\subsubsection*{3. 磁标势的泊松方程}

由于
\[
\boldsymbol H = -\nabla\phi_m
\]

代入 $\boldsymbol\nabla\cdot\boldsymbol H = \rho_m$ 得

\begin{equation}
\nabla^2 \phi_m = -\rho_m
\end{equation}

该方程形式与静电学中的泊松方程完全一致：
\[
\nabla^2 \phi = -\frac{\rho}{\varepsilon_0}
\]

因此磁标势的解为

\begin{equation}
\phi_m(\boldsymbol r)
=
\frac{1}{4\pi}
\left(
\iiint
\frac{\rho_m(\boldsymbol r')}{|\boldsymbol r-\boldsymbol r'|} dV'
+
\iint
\frac{\sigma_m(\boldsymbol r')}{|\boldsymbol r-\boldsymbol r'|} dS'
\right)
\end{equation}

随后得到

\begin{align}
\boldsymbol H &= -\nabla \phi_m \\
\boldsymbol B &= \mu_0(\boldsymbol H + \boldsymbol M)
\end{align}
